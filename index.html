How to use this

Each console below is a full page: a clickable product-screen mock, a persona and user journey, a realistic story grounded in Radical AI's actual customers and stated numbers, and a citation trail.

Journey stepsClick through the numbered steps atop each console — the screen actually changes state, it isn't a static image.
